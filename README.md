# Anna Ambratt — portfolio

En responsiv, svenskspråkig portfolio för Anna Ambratt. Webbplatsen är byggd i vanlig HTML, CSS och JavaScript utan byggsteg eller externa bibliotek.

## Publicera med GitHub Pages

1. Öppna **Settings → Pages** i GitHub-repot.
2. Välj publicering från grenen `main` och mappen `/(root)`.
3. Spara. GitHub Pages publicerar då `index.html` och webbplatsens relativa tillgångar.

## Personliga filer

- `assets/Anna-Ambratt-CV.pdf` är den CV-PDF som länkas från kontaktdelen.
- `assets/anna-ambratt.jpg` är porträttet som visas i heron och återkommer i bildcollaget. Byt filen på samma sökväg för att uppdatera bilden.
- `assets/anna-vardag.jpg` är det andra porträttet i det personliga bildcollaget.
- Porträtten är exporterade för webben i sRGB och hög kvalitet. Collaget använder samma varma färger och mjuka former som resten av sidan.
- `assets/citron-gren.svg` är den diskreta botaniska detaljen i hero och bildcollage.
- LinkedIn-knappar i navigation, kontaktsektion och sidfot länkar till Annas profil i en ny flik.

Kontaktuppgifterna och meritförteckningen på sidan är hämtade från Annas bifogade CV. LIA-inriktningar och den personliga introduktionen följer briefen.
